# yourName.py

**Program Description**

This Python code is a simple name validation script that continuously asks the user for their name until they enter a specific predefined name, 'your name'. Once the correct name is entered, the program displays a thank you message.

**How it Works**

1. The program initializes an empty string variable named `name`.
2. It enters a while loop that checks if the `name` variable is not equal to 'your name'. This loop will continue indefinitely until the condition is met.
3. Inside the loop, it displays a message asking the user to enter their name.
4. It then uses the built-in `input()` function to get the user's input and store it in the `name` variable.
5. Once the user enters 'your name', the while loop condition is met, and the loop exits.
6. After the loop exits, the program displays a thank you message.
